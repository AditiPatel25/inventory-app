# inventory-app

A full-stack inventory management application built with **Node.js**, **Express**, and **PostgreSQL**. This project allows users to manage categories and inventory items for an imaginary store using full CRUD functionality.

Users can:
- View all categories
- Browse items within a category
- Create new categories and items
- Update existing inventory data
- Delete categories or items
- Manage inventory relationships through a PostgreSQL database

### Tech Stack

- **Backend:** Node.js, Express
- **Database:** PostgreSQL
- **Styling:** CSS
